# bunny days｜小兔的首爾假期

繁體中文、Miffy 繪本風格的五天四夜首爾互動旅行手帳。原生 HTML / CSS / JavaScript，無建置步驟或外部執行依賴。

## 線上網站

[開啟首爾旅行手帳](https://nibbles724bot.github.io/TravelSeoul/)

## 開啟

直接以瀏覽器開啟 `index.html`，或執行 `python3 -m http.server 8000`，瀏覽 http://localhost:8000 。可部署至任何靜態主機（含 GitHub Pages）。

## 功能

- 五天行程頁籤與鍵盤左右鍵、Home / End 切換
- 景點地圖搜尋連結
- 第三天上午半天醫美、下午新沙與 COEX，第四天聖水與首爾林
- 行前清單（localStorage 僅保存在本機；儲存不可用時仍可操作）
- 韓元預算試算，可自行調整醫美預留額度
- 列印時包含全部五天行程
- 響應式排版與減少動態偏好支援

未指定出發日期、航班及療程，因此時間為參考，不含預訂。醫美是否施作、恢復期與適航性需由合格醫師個別評估。旅遊及醫療參考連結收錄於網站內，查核日期 2026-11-26。

視覺為 Miffy 風格靈感的自製向量插畫與版面，非官方合作。未使用官方圖檔。
